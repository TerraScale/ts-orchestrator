# Estimated seconds per test under scripts/ci/race-test.sh on the CI builder
# (go test -race, GOMAXPROCS=2). Only the order and packing of shards depend
# on these numbers; every listed test runs whatever they say. Columns:
#
#   <package> <test or glob> <seconds>[/<seconds under -short>] [cpu|solo|idle|norace|norace solo]
#   <package> - <seconds>[/<seconds under -short>]
#   rest - <seconds>[/<seconds under -short>]

#
# cpu tests are packed into shards by cost, solo tests get a CPU shard of
# their own and idle tests a shard in the pool for timer-bound process labs.
# norace tests are packed into CPU shards that run without the race
# detector: mark only tests whose code paths start no goroutine, and give
# their cost without it. "norace solo" gives one such test its own shard.
# The first matching line wins; a test no line matches costs one second.
# Packages that are not sharded are packed into one group per CPU worker slot
# per CI machine
# by their "<package> -" cost; "rest" is the cost of each one without a line.
#
# Refreshed from CI run 883 (main, 2026-10-03) and local timings at
# GOMAXPROCS=2 scaled to the builder. After a
# large change, refresh them from a CI log: each shard prints
# "race <shard> elapsed=<seconds>s", and `go test -race -json -run '^Name$'`
# times one test. Keep the numbers rounded; changing a cpu estimate can move
# tests between shards, which re-runs those shards once.
