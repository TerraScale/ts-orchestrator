## Process evidence: caller causal context (A2, not acceptance)

TerraBase PR #188 (merge `d39033ec`) defines how a write's `observed` causal
context relates to replication. The S0 repro and its readiness impact are in
[D03](d03.md#process-evidence-caller-causal-context-a2-not-acceptance).

For each entry, the member compares it with the target document's history
there: the per-origin maximum of the document's manifest context and sibling
events. The rule is documented in TerraBase
`docs/server-http-json-first-caller-decision.md` and the client OpenAPI.

- **Accepted:** the entry is within that history. The member's own origin is
  also accepted up to its source high-water, because every new local event
  already observes all earlier local events.
- **`503 dependencies_unavailable`:** the entry is another signed member's
  origin, beyond this member's contiguous applied prefix for it. The caller
  read on a member that is ahead. Nothing is written, and the identical
  request succeeds once replication applies those events.
- **`400 invalid_request`:** every other entry, as on local-v1. That covers
  an unsigned origin, an unproduced local event, and an applied event outside
  the document's history. An invalid entry takes precedence over an unapplied
  one.

Neither outcome withdraws readiness.
`terrabase_document_causal_context_rejections_total{reason}` counts
rejections.

The two-member Fast test
`server_fast::distributed_client_process::replication::signed_v2_https_classifies_observed_context_without_closing_readiness`
covers the replication path:

- B commits while A is down, and A starts alone. On A, the context read on B
  returns 503 `dependencies_unavailable`, A stays ready, and the document
  stays absent.
- After B restarts and replication applies its event, the identical request
  commits on A and supersedes the observed sibling, leaving one sibling with
  context `[A:1, B:1]`.
- A later valid write replicates to B.

CI evidence: merge commit `d39033ec`, push run 12528 (#1140), Fast job 27228
(3m41s): the test passed. Main `3809539b`, run 12529 (#1141), Fast job 27231:
the test passed.
