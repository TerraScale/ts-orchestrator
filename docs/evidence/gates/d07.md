## Required result

[GOAL §9 D07](../../../../GOAL.md#minimum-end-to-end-acceptance-scenarios):
`psql` connects using documented TLS and credential handling; supported reads,
mutations and transaction commit/rollback behave correctly; changes replicate
and retry safely; unsupported SQL is rejected before side effects; table and
database grants are enforced. This is an M2 gate and not an M1 prerequisite.
