## Process evidence: caller causal context (A2, not acceptance)

An authenticated writer could take a TerraBase member out of service with one
request. S0 reproduced it on TerraBase `cd6b5e5d` with the real two-member
Fast fixture:

1. A commits DOCUMENT.
2. B commits REVERSE_DOCUMENT, and A applies it.
3. On A, a commit to the absent STALE_DOCUMENT with observed
   `[A:1, B:1]` returns `503 {"error":{"code":"stored_corruption"}}`.

A then logs `document operation failed; withdrawing readiness
cause=stored_corruption`, and `/readyz` stays down. The producer classified
caller input as stored corruption. An exact-ID retry whose observed context
claimed its own event had the same effect.

TerraBase PR #188 (merge `d39033ec`) classifies caller causal context as
input; no observed value withdraws readiness. The rule is in
[D04](d04.md#process-evidence-caller-causal-context-a2-not-acceptance). The
regression test
`server_fast::distributed_client_process::replication::signed_v2_https_classifies_observed_context_without_closing_readiness`
covers:

- the S0 repro, an unsigned origin and an unproduced local event: each
  returns 400 `invalid_request`, with `/readyz` still ready and the member
  still committing and replicating afterwards;
- a retry that claims its own event: returns 409 `idempotency_conflict`.

Evidence is from the local process fixture and Fast CI, not from the live
cells:

- **Fails on TerraBase `97aad021`** (before the fix), locally:
  `stored_corruption` instead of the documented code.
- **Passes on the merge commit `d39033ec`:** push run 12528 (#1140), Fast
  job 27228. The log shows `Compiling tb-document`, `Compiling tb-server` and
  `signed_v2_https_classifies_observed_context_without_closing_readiness ...
  ok`; 190 tests passed.
- **Passes on main `3809539b`:** run 12529 (#1141), Fast job 27231, and a
  local rerun.

The PR-head Fast run on `4e67be29` (run 12493, job 27131) reused a stale
target slot and did not run the test. TerraBase #189 fixed that defect. The
pre-rebase head `18a86c22` ran the test and passed (run 12477, job 27071).
