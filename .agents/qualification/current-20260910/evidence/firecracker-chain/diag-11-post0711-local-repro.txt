## 4. Root cause of the unchanged crash
initialgrant readMaterial (src/orchestrator/initialgrant/files.go:187-209) opens EVERY
ancestor directory with O_RDONLY|O_DIRECTORY. open() on a directory needs READ
permission on that directory (not just +x traversal). 0711 gives others only --x,
so the capability-less orchestrator still gets EACCES at openat(/etc, "terrascale") —
same failure point and same redacted journal text as with the original 0700.
